# Team rifle models

`ak47.obj` and `m16.obj` are original low-poly models generated by
`generate.py`. The rifles point along +Z and use +Y as up. The AK-47 is black;
the M16 is charcoal and gunmetal. Each MTL material uses a generated 1-pixel
PNG swatch because the Vulkan OBJ renderer reads diffuse textures.

Run `python3 assets/weapons/generate.py` from the repository root to rebuild
the OBJ, MTL, and PNG files. The models are used both in first person and as
dropped pickups. Team assignment, scale, and placement are in
`client/gamemode/weapon_profiles.hh`.
